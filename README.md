# bgmm

Fits Gaussian mixture models with belief-based and soft-label methods.

Compatibility updates by Renova.

Makes a factor-class check scalar and updates the internal plot helpers and package documentation.

## Installation

```r
install.packages("bgmm", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.8.5.9001` is based on [CRAN 1.8.5](https://cran.r-project.org/package=bgmm).
